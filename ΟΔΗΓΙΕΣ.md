# Διόρθωση σύνδεσης Fraud Analytics

**Σωστό endpoint:** `http://127.0.0.1:8003/simulation/sequential`

Η έκδοση του main χρησιμοποιεί `APIRouter(prefix="/simulation")`, άρα το απλό `/sequential` δεν υπάρχει. Δεν τροποποιούμε τον αλγόριθμο της διπλωματικής.

## 1. Αντικατάσταση αρχείων

Από το ZIP αντέγραψε στον υπάρχοντα φάκελο `C:\Users\PATRI\fraud-decision-analytics` (με αντικατάσταση):

- `scripts\import_from_thesis_api.py`
- `dashboards\thesis_decision_dashboard.py`

Κράτησε προηγουμένως backup του φακέλου. **Μην αντικαταστήσεις το main `dummy thesis`.**

## 2. CMD 1 — Main API

```cmd
cd /d "C:\Users\PATRI\dummy thesis"
.venv\Scripts\activate.bat
python -m uvicorn app.api.main:app --host 127.0.0.1 --port 8003
```

Άφησε το CMD ανοιχτό.

## 3. CMD 2 — Analytics

```cmd
cd /d "C:\Users\PATRI\fraud-decision-analytics"
.venv\Scripts\activate.bat
set "THESIS_API_BASE_URL=http://127.0.0.1:8003"
findstr /N /C:"/simulation/sequential" scripts\import_from_thesis_api.py
python scripts\import_from_thesis_api.py
```

Περίμενε το `Done: ...fraud_investigation.db`. Μετά:

```cmd
python -m streamlit run dashboards\thesis_decision_dashboard.py
```

Αν εμφανιστεί HTTP 404 στο **σωστό** endpoint, διάβασε το `Response:` που θα δώσει ο importer: μπορεί να λείπουν δεδομένα ή το μοντέλο από το `dummy thesis`, όχι το endpoint.
